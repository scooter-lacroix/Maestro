# TrackLens Web Highlighter

Text selection and highlighting library for TrackLens annotation system.

## Overview

This package provides:
- Text selection API wrapper
- Highlight rendering for annotations
- Annotation marker management
- Selection range helpers

## Development

```bash
# Build
npm run build

# Run tests
npm test
```
