# TrackLens Shared

Shared utilities for TrackLens - compression, storage, types, helpers.

## Overview

This package provides:
- Compression utilities (deflate compression for walkthroughs)
- Storage helpers (local storage, IndexedDB)
- Shared TypeScript types and interfaces
- Helper functions for parsing, formatting

## Development

```bash
# Build
npm run build

# Run tests
npm test
```
